# PageNest 1.10.2

PageNest 1.10.2 聚焦视频知识笔记、网页 AI 总结可靠性和微信公众号离线保真。

### 视频知识笔记

- 视频截图现在可以生成更完整的知识型笔记。
- 自动整理内容摘要、关键知识点、画面关键信息和上下文不足提示。
- 提升 AI Provider 实际返回格式的兼容性，同时继续拒绝不安全或错误类型的响应。
- 增强不泄露密钥、请求正文或截图数据的安全诊断日志。

### 网页 AI 总结

- AI 总结失败状态现在会在 Popup 和离线页面中明确显示，网页正文与图片仍会正常保存。
- Provider 请求最多两次，减少无效重复请求和等待。
- 仅保存网页模式完全不调用 AI，也不再显示假的空 AI 总结。
- 改进 OpenAI-compatible Provider 返回内容的结构化解析与错误脱敏。

### 微信公众号

- 新增范围严格限定于 `mp.weixin.qq.com` 的 `wechat-article` 保真路径。
- 改善文章标题、作者、阅读时间、颜色、边框、背景及 flex/grid 布局保留。
- 改善 inline 小图片和 emoji 的离线保存。
- 继续删除危险脚本、事件处理器、远程活动资源和不安全样式。

### 界面

- 移除新网页收藏中的“收藏备注”。旧客户端发送的字段仍保持协议兼容，历史文件不会被改写。
- 保存模式增加清晰的速度与耗时说明，不承诺固定秒数。

### 升级

普通用户直接运行最新的 `PageNest-Setup.exe` 即可升级。安装器会保留已有 Vault、连接配置和用户配置。

PageNest 完整功能需要 Windows 本地组件。普通网页保存与视频截图不要求配置 AI；启用 AI 模式后，所需正文或图片会发送给用户自己配置的 Provider。
