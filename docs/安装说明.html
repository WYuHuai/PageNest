PageNest v1.8.0

三步完成安装：安装程序、浏览器扩展、Obsidian Viewer。

1安装 PageNest

下载并运行 PageNest-Setup-1.8.0.exe，选择一个已经包含 .obsidian 文件夹的 Obsidian 知识库。普通用户不需要下载源码或安装 Python。

  • 不需要安装 Python。
  • 不需要安装 Node.js。
  • 不需要手工填写连接 token。
  • 安装完成后 Service 自动启动，并在登录 Windows 后自动启动。

安装器目前没有 Authenticode 签名，Windows SmartScreen 可能显示“未知发布者”。PageNest 不要求关闭 Microsoft Defender。

2加载 Edge / Chrome 扩展

  1. 打开 edge://extensions/ 或 chrome://extensions/。
  2. 开启“开发人员模式”。
  3. 点击“加载解压缩的扩展”。
  4. 选择下面的文件夹：
%LOCALAPPDATA%\Programs\PageNest\Extension

Edge Add-ons 正式上线后，这一步会改为从商店安装；当前 Public Beta 仍使用安装器内置扩展。

3启用 Obsidian Viewer

重启 Obsidian，打开“设置 → 第三方插件”，启用 PageNest Viewer。

随后打开网页 → 点击 PageNest → 选择保存位置 → 点击“保存到 Obsidian”。

更换 Obsidian 仓库

打开“PageNest → 设置 → 当前 Vault → 更换仓库”，选择新的 Obsidian Vault。

  • 新收藏进入新 Vault。
  • 原 Vault 中的文件不会移动或删除。
  • 选择会保存，PageNest 或 Windows 重启后仍然有效。
  • 旁边的刷新按钮只重新扫描当前 Vault 内的文件夹。

连接异常时

  1. 在 Popup 设置页点击“重新连接”。
  2. 检查 PageNest Service 是否已安装。
  3. 从开始菜单打开“PageNest 运行状态”。
  4. 仍无法恢复时，重新运行安装器进行修复。

正常使用不需要每天手动启动 Service。Extension 会使用已有 token，在 8765、18765、28765 三个已知本地端口中进行有限重新发现。
