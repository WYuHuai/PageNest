PageNest

1. 运行安装程序

双击 PageNest-Setup-1.8.0.exe，选择一个已经包含 .obsidian 文件夹的 Obsidian 知识库。安装包已包含 Python 运行环境和本地服务，无需另外安装 Python 或填写令牌。

2. Edge / Chrome 扩展

  1. 打开 edge://extensions/ 或 chrome://extensions/。
  2. 开启开发人员模式。
  3. 加载 %LOCALAPPDATA%\Programs\PageNest\Extension 文件夹。

连接信息已由安装程序配置。

3. Obsidian 查看器

重启 Obsidian，在“设置 → 第三方插件”中启用 PageNest Viewer。安装程序已把查看器复制到所选知识库。

可选：智能整理

需要时在扩展中填写 OpenAI 兼容接口。快速模式只分析文字；深度模式额外分析最多 8 张图片；仅保存原文不会调用模型。

收藏结果

每篇网页生成一个 .pagenest 文件，正文与成功下载的图片都封装在其中；旧 .hermes 文件仍可由 PageNest Viewer 打开。

页面断网可读；原网站删除后，已成功内嵌的内容仍然存在。
