安装 PageNest 浏览器扩展

只选择安装程序刚刚打开的 Extension 文件夹。不要选择下载的源码目录或其他 PageNest 文件夹。

%LOCALAPPDATA%\Programs\PageNest\Extension
  1. 打开 edge://extensions 或 chrome://extensions。
  2. 开启“开发人员模式”。
  3. 点击“加载解压缩的扩展”，选择上面的 Extension 文件夹。
  4. 打开 PageNest 扩展；本地服务地址和连接令牌已经由安装程序配置。

如果扩展显示“未获本机服务授权”，请删除选错的扩展并重新加载上面的文件夹。

扩展正式上架浏览器商店后，这一步会替换为商店中的“安装”按钮。
