安装 PageNest 浏览器扩展

普通用户请从 Microsoft Edge Add-ons 安装 PageNest，以获得官方商店审核与自动更新。

安装完成后打开扩展；看到“PageNest 后台服务已连接”即可使用。

开发或故障恢复

只有商店版本暂不可用时，才加载安装器保留的 unpacked 备用副本。请勿加载下载的源码目录或其他 PageNest 文件夹。

%LOCALAPPDATA%\Programs\PageNest\Extension
  1. 打开 edge://extensions 或 chrome://extensions。
  2. 开启“开发人员模式”。
  3. 点击“加载解压缩的扩展”，选择上面的 Extension 文件夹。
  4. 打开 PageNest；本地服务地址和连接令牌已经由安装程序配置。

如果扩展显示“未获本机服务授权”，请删除选错的扩展，并重新运行 PageNest 安装器。
